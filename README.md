# Javaab Monorepo

Welcome to the Javaab monorepo! It contains the backend (FastAPI), web UI (React), and mobile app (Expo) for the platform.

## Structure
- `backend/`: FastAPI application, APIs, and AI routing logic.
- `web/`: React frontend (populated via Lovable export).
- `mobile/`: React Native mobile application.
- `scripts/`: Data ingestion and cache building scripts.

## Setup
Refer to individual READMEs within each folder or `docker-compose.yml` for quick startup.
